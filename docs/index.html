KnowledgeBaseMCP#

AI-generated

These pages were written with Claude Opus 5.5 and are under human review.

An MCP server and command line for Open Knowledge Format (OKF) v0.2 knowledgebases: directories of Markdown concepts with YAML frontmatter, grouped into bundles. It checks, maintains and imports them. It cares how a concept is written, never what it says.

One contract, three users:

  • An agent over MCP: every tool, with diffs before writes and a confirmation prompt before anything records a human.
  • CI: lint with GitHub annotations or SARIF, a baseline for old findings, since= for pull requests.
  • A person at a terminal, no AI involved: help, readable text output, and --attest to sign your own reviews.

Local files only. No network. Never writes to git. One Python file, run with uv.

Quickstart#

# start a bundle
uv run KnowledgeBaseMCP.py init bundle=eng apply=true

# write a concept
uv run KnowledgeBaseMCP.py create eng/runbooks/deploy \
    type=Playbook description="How we deploy."

# what's wrong, each with a fix; then the mechanical repairs
uv run KnowledgeBaseMCP.py lint format=text
uv run KnowledgeBaseMCP.py fix apply=true

# any tool: what it does, its arguments
uv run KnowledgeBaseMCP.py help move

Register it with Claude Code:

claude mcp add knowledgebase --env KB_ROOT=/path/to/kb \
    -- uv run /path/to/KnowledgeBaseMCP.py
